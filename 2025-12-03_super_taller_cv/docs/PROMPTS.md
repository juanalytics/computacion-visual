## Lineamientos

1. Cada vez que se use una IA para generar código o contenidos, registrar:
   - Prompt exacto o resumen fiel.
   - Fragmentos del resultado que se integraron.
   - Referencia al archivo y commit.
2. Si una salida se desecha, puede anotarse en una sección de experimentos para mantener trazabilidad.
3. Anexar capturas o enlaces si la herramienta no permite exportar texto plano.

Esto ayuda a mantener transparencia en el uso de IA conforme a la rúbrica.
