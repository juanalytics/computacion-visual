# Recursos web compartidos

Espacio para componentes reutilizables (estilos, assets web, scripts comunes) que puedan ser consumidos por el dashboard, la escena Three.js o cualquier frontend adicional.

## Ideas iniciales

- Biblioteca de UI (botones, HUD, tipografías).
- Hooks/utilidades de WebSocket para proyectos React.
- Estilos globales (tema visual consistente con Unity/Three.js).
- Componentes para incrustar métricas o reproductores de video.

Mantén esta carpeta ligera y documentada para fomentar la reutilización.
